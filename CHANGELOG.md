# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/).

## [1.2.12] — 2026-07-29

### Added

- MV3 service worker with the anonymous Premium11 heartbeat (install/update/ping, 24 h throttle) and the uninstall farewell page.
- Public repository baseline: README, docs, CI, issue templates, and the English-only documentation surface.

### Changed

- Popup: the Premium11 brand mark moves above the cards as a real link (focus ring, reduced-motion support).
- Popup: scrollbars use solid Premium11 green with tuned hover/active states in light and dark themes.

## [1.2.11] — 2026-07-21

### Changed

- Premium11 brand identity in the popup: Montserrat, brand tokens, green scrollbar.

## [1.2.10] — 2026-07-21

### Added

- Branded popup UI baseline shipped to the Chrome Web Store.

## Earlier

- Versions 1.0.0 through 1.2.9 evolved in the Chrome Web Store listing; this repository starts from the 1.2.10 snapshot.
