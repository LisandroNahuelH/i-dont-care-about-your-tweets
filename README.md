# I Don't Care About Your Tweets

Extensión MV3 para X.com que agrega tres botones en la parte superior de cada post:

- `Bloquear`
- `Silenciar`
- `No me interesa`

El proyecto se escribe en TypeScript estricto por la política base del repo, pero el resultado instalable es JavaScript simple dentro de `dist/`.

## Uso

1. `npm install`
2. `npm run verify`
3. Cargar `dist/` como extensión descomprimida en Chrome o Edge.

## Scripts

- `npm run build`
- `npm run typecheck`
- `npm run lint`
- `npm run test`
- `npm run verify`
